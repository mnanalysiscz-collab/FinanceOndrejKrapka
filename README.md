# FinanceOndrejKrapka – první šablona

Statická jednostránková šablona pro osobní web Ondřeje Křapky.

## Soubory

- `index.html` – obsah webu
- `styles.css` – kompletní design a responzivita
- `script.js` – mobilní menu a animace při scrollování
- `assets/ondrej-hero.jpg` – horizontální fotografie
- `assets/ondrej-portrait.jpg` – portrétní fotografie

## Nahrání na GitHub

Nahraj všechny soubory do kořene repozitáře tak, aby složka `assets` zůstala zachována.

## GitHub Pages

V repozitáři otevři:

1. Settings
2. Pages
3. Source: Deploy from a branch
4. Branch: `main`
5. Folder: `/ (root)`
6. Save

Po chvíli se zobrazí adresa publikovaného webu.

## Poznámka k formuláři

Formulář je nyní demonstrační a používá `mailto:`. Před ostrým spuštěním je potřeba jej napojit na bezpečnou formulářovou službu nebo vlastní backend.
